## ⚙️ How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Abhishek-Saini-Coder/portfolio.git
   ```
2. Open the folder:
   ```bash
   cd portfolio
   ```
3. Run the project:  
   - Simply open `index.html` in your browser  
   - Or use a local server:  
     ```bash
     npx serve .
     ```
